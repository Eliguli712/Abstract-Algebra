# 逐区域与深度的柔和渐变

每个区域以规范化后的整数矩阵作为身份，使用代表点 z=g(0.137+1.63i)。
通过 Cayley 变换 w=(z−i)/(z+i) 得到角位置及径向坐标。
归一化径向量为 R=1−exp(−2 atanh|w|/3)。
角位置通过周期性的 sin 与 cos 进入色相，在角度分支两侧连续衔接。
矩阵字符串的两次 FNV-1a 散列提供区域相位与饱和度相位。

颜色由四个量共同决定：最短字长 n、径向位置 R、角位置、区域相位。
“深度色移”控制 n/18 对色相和明度的权重；
“区域色差”控制区域相位对色相、饱和度和明度的影响。
自适应彩虹使用循环色相，青蓝与紫兰预设使用较窄色域。

颜色表始终对深度 18 内的全部 35,416 个区域建立，显示深度与视野变化不会重新定义颜色。
量化 RGB 出现碰撞时，优先使用最近的未占用整数颜色，局部位置用尽后按确定次序寻找可用颜色。
量化基色保证互异；内部渐变与透明混合产生最终像素色彩。

相邻 gS、gT、gT⁻¹ 区域中已枚举的基色在线性光空间求均值，协调描线与内缘。
足够大的区域具有自己的径向光场：中心柔亮、中段回到基色、内缘吸收邻域颜色并稍微压暗。
光场以几何代表点为中心，随图形一起缩放。
尺寸不足约 9 像素的区域使用各自基色，保留实轴附近的细小区域颜色变化。
柔光使用同色低透明度宽描线，金色轮廓标出标准基本域。

实现位于 sl2z/enhancements.js。测试检查三个预设的基色唯一性、显示深度变化时的稳定性和控件响应。
