# 模群的上半平面 · 离线互动版

下载 index.html，用浏览器打开即可互动。全部样式、群计算和控件已打包，无需账户或网络。
GitHub 的代码预览页显示源码；下载后由浏览器打开。

## 主要控制

- 点选弯边区域，显示整数矩阵、尖点和字长。
- 上一块／下一块及逐区滑杆按广度优先队列选择区域。
- 深度滑杆及少一层／多一层控制 0–18 层展开；自动展开每 900 毫秒增加一层，在 18 停止。
- S、T、T⁻¹ 对当前矩阵左乘；支持聚焦、撤回选区、复位、拖动、滚轮和双指缩放。
- 三个预设：自适应彩虹、青蓝深海、紫兰暮光；区域色差与深度色移独立调整。
- 填充、描线、柔光可以分别切换；SVG 和三倍分辨率 PNG 保留当前视野与颜色。

## 键盘

| 按键 | 操作 |
| --- | --- |
| S / T / Shift+T | 施加 S / T / T⁻¹ |
| ← / → | 上一块 / 下一块 |
| [ / ] | 减少 / 增加深度 |
| ＋ / − | 放大 / 缩小 |
| F / 0 | 聚焦 / 复位 |
| 空格 | 自动展开 / 暂停 |
| C / L / G | 填充 / 描线 / 柔光 |

控件获得键盘焦点时，保留控件自身的键盘行为。
复位恢复标准基本域、深度 16 和默认视野，保留颜色与线条设置。

## 源码与复现

base-fragment.html 保存基础几何与原有互动；enhancements.js 添加着色、逐区与导出；
controls.html 与 standalone.css 提供独立页面控制及响应式样式。

在仓库根目录运行：

    python3 scripts/build_sl2z.py
    npm ci
    npm test

修改源码后重新构建 index.html。原始静态图由 scripts/render_sl2z.py 复现。
数学和着色定义见 docs/SL2Z_MATHEMATICS.md 与 docs/SL2Z_COLOR_GRADIENTS.md。

DOM 测试检查控件事件和坐标重算；浏览器外观、PNG 下载及实体双指手势需实际浏览器检查。
